# Price-history-only stochastic volatility screen

User-authorized parallel campaign. Credit runs are untouched.

`DESIGN.md` freezes the market, information, costs, training and independent selection/evaluation protocol. `audit_worker.py` reproduces the uploaded diagnostic unchanged on a managed GPU. `model.py` replaces scheduled shocks with Bernoulli arrivals under both P and Q, with future arrivals included in option prices. A GRU observes only causal prices, time and its holding. `diagnostic.py` gates training on event-study pattern, multi-maturity pricing precision/convergence, martingale/tower tests and independent cash-ledger reconciliation. `evaluate.py` computes paired cross-domain results and daily marked errors; marks never enter policy inputs.

`supervise.py` runs the stochastic diagnostic, waits for successful original reproduction, trains the three arms concurrently, then packages selected checkpoints into an independent evaluator. A failed scientific gate stops training. Each launcher has an independent managed state, timeout, incremental output sync, required artifacts and API-confirmed destruction. `monitor.latest.json` tracks GPU telemetry, trial progress, sync and failures every30seconds. `STATE.json` and `supervisor_failure.txt` identify stage/failure. Final output is `results.json`; until then no specialist performance is established.

All numerical work runs on rented GPUs. Local scripts only package, launch, monitor and copy artifacts. Dependencies use uv and pinned managed CUDA JAX0.11.2/Equinox0.13.8 rather than the upload's JAX<0.8 range; resolved worker environment is exported. `source_hashes.json` pins source/config; each run preserves its submitted package and hashes. Selected checkpoints are atomic and exported before cleanup.

Statistical limits: one training initialization; episode bootstrap intervals are conditional on fitted models. Entropic objective is estimated on finite batches/episodes; these experiments do not establish population exponential-moment integrability for unbounded lognormal stock/payoff tails. Daily marked diagnostics use256 independent episodes and4096 Q paths; independent price-replicate discrepancies are reported to expose quote-noise contamination. No claim of daily-risk ordering should outrun that precision. Variance cap1 is a model definition, not a convergence tolerance or calibration.
